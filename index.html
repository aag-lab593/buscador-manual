Preparar búsqueda

Las fuentes ATS pueden consultarse juntas mediante Google. Las bolsas de empleo y agregadores sin API pública validada se abren por separado.

La búsqueda conjunta cubre únicamente páginas ATS indexadas por Google. Los portales con buscador propio aparecen más abajo y requieren una búsqueda separada. No hay resultados consolidados ni APIs conectadas.

Consulta directa de ATS · beta

Consulta APIs públicas de empresas seleccionadas, sin pasar por Google. Cada proveedor muestra si respondió o falló. Las fuentes sin API disponible no se contabilizan.

Cuando encuentres una vacante

Abre la publicación oficial, verifica que esté vigente y que admita candidatos en Ecuador. Copia su enlace y pégalo en Career Office con «Ejecuta JAS 9.6: URL».

No se envían postulaciones ni se transfieren datos automáticamente. Las APIs directas de Ashby, Greenhouse y Lever todavía no están conectadas.
